# Vissy Vandiya — Personal Website

Website profil pribadi Vissy Vandiya, Learning Solution Section Head di BINUS Corporate Learning & Development.

## Desain dan fitur

- Desain minimalis dengan cobalt blue (#2145e8), putih, dan tipografi editorial.
- Layout responsif; navigasi ponsel, accordion fokus, filter karya, panel sumber, serta salin email.
- HTML, CSS, JavaScript, dan ilustrasi SVG mandiri tanpa dependensi eksternal.
- Metadata SEO, Open Graph, dan structured data Person.
